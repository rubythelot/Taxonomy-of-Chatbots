# Taxonomy of chatbots

A React/Vite product strategy tool for mapping chatbot choices across three dimensions:

- Core intelligence
- Interaction pattern
- Complexity

The generated recommendations are based on the supplied prototype taxonomy and the accompanying PDF research. The visual system uses the bundled AREA 17 Suisse font assets and design tokens.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production build is emitted to `dist/`.
